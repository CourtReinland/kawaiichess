# Demo Scope v1 - Kawaii Ouroboros

**Goal**: First playable Android demo (vertical slice)

## Must Have Features

### Core Systems
- 8x8 chess board with clean touch controls (tap to select, tap to move)
- 8–10 cute anime-themed pieces with distinct abilities
- Basic turn system (Player → Enemy AI)
- Capture the enemy King to win

### Roguelike Elements
- Simple node-based map (5–7 nodes)
- One battle per node
- Basic gold + relic rewards after victory
- "Rewind" on death (new run)

### Content
- 8–10 playable pieces (mix of Tier 1 and Tier 2)
- 3–4 enemy piece types
- 2–3 basic relics

### UI
- Board view
- Piece selection with ability description
- Simple recruitment / shop screen between battles
- Win / Lose / Rewind screens

### Technical
- Runs on Android (tested on physical device)
- 60 FPS target on mid-range phones
- Basic save system (current run state)

## Out of Scope for v1
- Full procedural map generation
- Complex piece synergies
- Animations & VFX
- Sound
- Multiple acts
- Meta-progression
- Polish

## Success Criteria
- Player can complete at least one full short run (start → 5 battles → win or rewind)
- Touch controls feel responsive
- At least 3 pieces have unique abilities that change how you play

**Target Timeline**: First testable build within 3–4 weeks of active development
